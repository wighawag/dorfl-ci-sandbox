## What to build

Add `isBlank(text)` in a new module `src/blank.js`: true when the string is empty or only whitespace. Add tests in `test/blank.test.js`.

## Acceptance criteria

- [ ] `isBlank` is true for empty and whitespace-only strings, false otherwise.
- [ ] `npm test` is green.
