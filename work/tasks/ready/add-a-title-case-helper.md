## What to build

Add `titleCase(text)` in a new module `src/title.js`: upper-case the first letter of every whitespace-separated word and lower-case the rest (`'hello WORLD'` becomes `'Hello World'`). Add tests in `test/title.test.js`.

## Acceptance criteria

- [ ] `titleCase` behaves as described, including for an empty string.
- [ ] `npm test` is green.

## Prompt

> Add the `titleCase` helper described above in `src/title.js` with tests in `test/title.test.js`.
