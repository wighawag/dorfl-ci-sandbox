## What to build

Add `countWords(text)` in a new module `src/words.js`: it returns the number of whitespace-separated words (0 for an empty or blank string). Add tests in `test/words.test.js`.

## Acceptance criteria

- [ ] `countWords` counts words and returns 0 for blank input.
- [ ] `npm test` is green.
