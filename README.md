# dorfl-ci-sandbox

A throwaway repository that exercises [dorfl](https://github.com/wighawag/dorfl)'s split CI workflows (lock, agent and apply jobs per item) end to end: intake, builds, tasking, the answer loop, protected paths and failure handling. The code is a tiny string-utilities library (`src/strings.js`, tested with `npm test`).

dorfl is installed from a pre-release tarball of its `main` hosted on `wighawag/dorfl-ci-sandbox-builds`, not from npm. Safe to delete.
